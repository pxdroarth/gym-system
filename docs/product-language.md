# Linguagem de produto

Referência de terminologia para documentação e interface. Use **Rede**, **Unidade**, **Matriz** e **Filial** nas telas e nos textos operacionais. `tenant` e `unit` são termos internos de código, API e banco.

**Histórico de Atividades** é o módulo de consulta. **Auditoria** é o mecanismo técnico que registra as ações. Consulte os [requisitos base](governance/requisitos-base.md) e a [matriz de permissões](governance/matriz-permissoes.md) para o alcance de cada perfil.

Um glossário completo e a revisão sistemática dos rótulos das telas permanecem pendentes.
